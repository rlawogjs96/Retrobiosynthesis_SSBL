# PolyketideClassifier: End-to-End Neuro-Symbolic Retrobiosynthesis Engine

**3-Head Reverse-Peeling GNN (`C1-Register PE` + `SynCat` Cross-Attention + `PATRO` Highway) + `SynKit` DPO Rewriting + Deterministic Modular Type I PKS/NRPS Solver**

---

## 1. Overview & Scientific Architecture

Complex polyketide and hybrid PKS-NRPS natural products undergo two distinct biosynthetic stages:
1. **Modular Assembly Line Synthesis ($M_0$):** Collinear extension of a starter unit (`LM`) across $N$ modules (`KS - AT - [KR - DH - ER] - ACP`) followed by terminal offloading (`TE` macrolactonization/macrolactamization/hydrolysis, `R` reductive release, or Dieckmann/tetronate cyclization).
2. **Post-PKS / Hybrid Tailoring Cascades ($M_0 \to M_1 \to \dots \to M_{\text{target}}$):** Multi-step enzymatic decorations and scaffold rearrangements (deoxysugar $O$-/$N$-glycosylations, Cytochrome P450 hydroxylations/epoxidations, $[4+2]$ Diels-Alderases, spirotetronate/tetramate cyclizations, polyether epoxide-opening zippers, Baeyer-Villiger insertions, SAM $O/C/N$-methylations, halogenations, carbamoylations, and NRPS thiazole/oxazole heterocyclizations).

This repository implements a **Two-Stage Hybrid Neuro-Symbolic Retrobiosynthesis Engine** that inverts post-PKS tailoring modifications step-by-step and then deterministically reads out the exact modular PKS assembly line:

\[
M_{\text{target}} \;\xrightarrow{\text{Stage 1: 3-Head Reverse-Peeling GNN + SynKit DPO Beam/MCTS}}\; M_0 \text{ (Nascent PKS Core)} \;\xrightarrow{\text{Stage 2: Deterministic PKS Solver}}\; \text{Modules } (M_0 \dots M_n), \text{AT, KR/DH/ER}
\]

## 2. Stage-by-Stage Pipeline Details

### Stage 0: Stereochemistry-Preserved Nascent PKS Core Generation (`scripts/01_generate_PKS_products.py` & `generate_by_family.py`)
- **Full Stereochemical Retention (`REMOVE_STEREOCHEMISTRY = False`):** Preserves all tetrahedral (`@`/`@@`, $R/S$) and olefinic ($E/Z$) stereocenters across both cyclic macrolactones (`lactonization`) and linear carboxylic acids (`thiolysis` / `carboxylic_acid`).
- **Multi-Family Long-Chain Scaffolds (1 to 14 Extension Modules):** Combines 1–2 module cores with 600 stereo-preserved 4–14 module scaffolds generated by `generate_by_family.py` across `other_cis_at`, `polyethers` (virtual epoxide-opening cascades), and `aromatic_polyene` into `data/processed/pks_cores_with_stereo_provenance.parquet`.
- **Atom & Bond Provenance (`extract_core_provenance`):** Every nascent core $M_0$ is pre-certified by `deterministic_stage/pks_terminal.py` and annotated with:
  - `is_pks_core_atom`: Ground-truth mask for Head 1 Core Shielding.
  - `atom_register_role`: Exact register role from C1 outward (`C1`, `alpha`, `beta`, `starter_backbone`, `alpha_branch`, `beta_oxygen`, `core_other`).
  - `cleavable_bridge_bonds`: Macrolactone/lactam ring-closure bonds.

### Stage 1B: 3-Head `ReversePeelingGNN` (`scripts/09_train_gnn_classifier.py`)
- **84-Dim Node Features + 16-Dim Edge Features (`smiles_to_graph`):**
  - **57-dim Stereochemical Atom Features:** Atomic number, degree, formal charge, total H count, hybridization, `@`/`@@` chirality tag, CIP $R/S$ configuration, ring size indicators ($r_3 \dots r_{\ge 8}$), carbonyl/hydroxyl/carrier-S flags, and prochiral $\text{CH}/\text{CH}_2$ indicator.
  - **7-dim C1-Register Parity Encoding (`compute_c1_register_encoding`):**
    \[
    p_{\text{reg}}(v) = \left[\frac{d_{\text{C1}}(v)}{20},\; d_{\text{C1}}(v) \bmod 2,\; \sin(\pi d),\; \cos(\pi d),\; \sin\left(\frac{\pi d}{2}\right),\; \cos\left(\frac{\pi d}{2}\right),\; \mathbb{I}[v = \text{C1}]\right]
    \]
  - **16-Step Random Walk Structural Encoding (`RWSE`) + 4-Dim Laplacian Eigenvector PE (`LapPE`).**
- **Three Cooperative Heads:**
  1. **Head 1 (`core_node_head`, `register_node_head`, `bridge_edge_head`):** Predicts per-atom PKS Core probability $p_{\text{core}}(v)$ (**`87.79%` accuracy**), protecting inline KR $\beta$-OH and AT $\alpha$-alkyl branches from being mistakenly stripped.
  2. **Head 2 (`exposed_node_head`, `SynCatSingleHeadAttention`, `PATROPathwayEncoder`, `rule_policy_head`):** Cross-attends 30 rule prototype queries over exposed non-core atoms and gates pathway context via a `PATRO` LSTM + Highway layer (**`89.3%` Top-1 / `99.8%` Top-3 rule accuracy**).
  3. **Head 3 (`value_head`, `cls_head`):** Predicts Distance-to-PKS Value $V(G) = \exp(-d / 2.5) \in [0, 1]$ (**`0.0909` MAE / `0.9330` AUPRC**).
- **Apple Silicon (`mps`) GPU Acceleration:**
  - Automatically detects `torch.backends.mps.is_available()` on macOS (`get_compute_device()`).
  - Vectorized `scatter_add_` group-wise softmax + fixed-multiple graph shape bucketing (`256` nodes / `1024` edges) eliminates Metal shader recompilation overhead.

### Stage 2: Deterministic PKS Solver (`deterministic_stage/` & `scripts/12_run_inference.py`)
- **`ringbreaker.py`:** Automatically detects and opens macrolactones (`lactonization`), macrolactams (`lactamization`), and cyclic hemiketals (`PF00975` TE cleavage, highlighted in pink in pathway diagrams) into the open-chain linearized acyl-ACP thioester (`S-C(=O)-...`).
- **`carbon_backbone.py`:** Enumerates C1-outward carbon backbones (`C1` $\to$ $\alpha_2/\beta_3 \dots$).
- **`predict_extenders.py`:** Identifies starter units (`mal`, `mmal`, `ahba`, `dhch`, `benz`, `prop`, `ibut`, `guan`, etc.) and $\alpha$-branch AT extenders (`mal`, `mmal`, `emal`, `allylmal`, `mxmal`, `hmal`).
- **`predict_reduction.py`:** Classifies $\beta$-oxidation state ($\beta$-keto, $\beta$-hydroxyl, enoyl, saturated) and **Keiser 2025 `KR` stereochemical subtypes (`A1`, `A2`, `B1`, `B2`, `C1`, `C2`)**, then executes a full forward assembly rebuild to certify constitution and stereochemistry (`status == "ok"` or `constitution_rebuild_match`).
